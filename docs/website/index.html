Corvus is a native desktop interface for signal-cli with an encrypted local chat history. Qt for Linux, Windows and macOS, plus a native SwiftUI app for the Mac.

Install Corvus Latest release

Open source · AGPL-3.0 · Linux · Windows · macOS

Features

Chats and groups

Read and send messages, including group chats, replies and reactions.

Files and media

Send and receive files, images, video and audio, with playback built in.

Full control

Edit or delete messages, archive chats and manage disappearing messages.

Stay notified

Desktop notifications, notification sounds and a tray or menu-bar icon.

Encrypted history

Your local chat history is encrypted and protected by the system keychain or a passphrase.

Make it yours

Customisable chat colours and appearance, with light and dark themes.

Install

Flatpak Linux · recommended

Sandboxed, includes signal-cli, updates with flatpak update.

flatpak remote-add --user --if-not-exists corvus __BASE_URL__/corvus.flatpakrepo
flatpak install --user corvus __APP_ID__

Or open the .flatpakref file with your software center.

Arch Linux

Download the package from the latest release.

sudo pacman -U ./corvus-*.pkg.tar.zst

Install signal-cli separately, for example from the AUR.

Other Linux

Per-user installer, no sudo needed.

tar -xzf corvus-linux-x86_64-installer.tar.gz
./install.sh

Needs Qt 6, QtKeychain and signal-cli on your PATH.

Windows

Use corvus-windows-x64-setup.exe. It can download signal-cli for you. A portable ZIP is available too.

macOS

Native SwiftUI app (corvus-macos-arm64.zip, macOS 14 or newer) or the Qt app (corvus-qt-macos-arm64.zip), both for Apple silicon.

All downloads are on the latest release page. The Flatpak keeps its own data, so link it to your Signal account as a new device on first start.
